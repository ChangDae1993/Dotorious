# FrameWork

`Assets/FrameWork` 폴더 전체를 `.meta` 파일과 함께 다른 Unity 프로젝트의 `Assets` 아래로 복사합니다.

- `Window > FrameWork > Presentation`: EventSO 전용 편집 창
- `Window > FrameWork > 2DObjectMaker`: 2D ObjectDefinition 전용 편집 창
- `Window > FrameWork > Settings`: 현재 게임에 자동 적용할 모듈 선택

Settings에서 체크를 끈 모듈은 Play와 빌드의 런타임 컴포넌트, 자동 부트스트랩 및 자동 설정을 실행하지 않습니다.
편집 창, SO, 프리팹과 명시적으로 배치한 데이터는 삭제하거나 변경하지 않습니다.
