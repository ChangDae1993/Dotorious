# 맵 제작용 Ingredients

10개 분류 × 10개 공통 테마 = 100개 프리팹입니다. 요청하신 폴더 이름 `Ingeredients`를 그대로 사용합니다.

같은 `v01`끼리, 같은 `v10`끼리 바닥·경사로·계단·발판·다리·벽·배경·장식의 계절과 재질이 대응합니다.

| 버전 | 테마 |
| --- | --- |
| v01 | 봄 초원 / SpringMeadow |
| v02 | 봄 꽃숲 / SpringBlossom |
| v03 | 여름 숲 / SummerForest |
| v04 | 여름 해안 / SummerCoast |
| v05 | 가을 황금숲 / AutumnAmber |
| v06 | 가을 단풍숲 / AutumnCrimson |
| v07 | 겨울 설원 / WinterSnow |
| v08 | 겨울 얼음 / WinterIce |
| v09 | 봄 이끼 유적 / SpringMossRuins |
| v10 | 겨울 석조 유적 / WinterStoneRuins |

## 배치

Project 창에서 원하는 프리팹을 Scene 또는 Hierarchy에 드래그하세요. 별도 SO 생성이나 목록 등록은 필요 없습니다. 위치·회전·크기는 Transform으로 조절합니다. 테마를 바꾸려면 같은 분류의 다른 버전 프리팹을 사용하세요. MapIngredient2D의 분류·버전·테마는 식별용이며, 값을 고쳐도 원본 이미지나 콜라이더가 재생성되지는 않습니다.

| 폴더 | 기본 크기 / 용도 | 기준점 |
| --- | --- | --- |
| Ground | 폭 4, 깊이 2 / 일반 바닥 | 왼쪽 표면 (0,0) |
| Ramps | 폭 4, 상승 1 / 약 14도 경사 | 낮은 쪽 왼쪽 끝 |
| Stairs | 폭 4, 0.2씩 5계단 / 상승 1 | 첫 계단 진입 높이 |
| Platforms | 폭 3, 두께 0.25 / 아래에서 통과 가능한 발판 | 왼쪽 표면 |
| Bridges | 폭 6 / 고정 다리 | 왼쪽 표면 |
| Walls | 폭 2, 높이 4 / 막힌 길, 벽, 기둥 | 왼쪽 아래 |
| Foreground | 큰 앞배경 / Background1 | 이미지 하단 중앙 |
| Background | 뒷배경 / Background2 | 이미지 하단 중앙 |
| FarBackground | 먼 배경 묶음 / Background3 | 묶음 하단 중앙 |
| Decorations | 테마에 맞는 바위·덤불·유적 장식 / 비충돌 | 이미지 하단 중앙 |

- 바닥이 (0,0)에 있으면 다음 바닥은 (4,0), 경사로는 (4,0)에 이어 붙일 수 있습니다. 그 경사로 위쪽에 이어지는 바닥은 (8,1)입니다.
- 반대 방향 경사로·계단은 Transform의 X Scale을 -1로 바꿉니다. 경사로의 낮은 쪽 기준점이 왼쪽이 아니라 오른쪽이 됩니다.
- 계단은 기존 몬스터 AI의 작은 턱(0.35)보다 낮은 0.2 높이를 사용합니다. 스케일을 크게 늘리면 적의 턱 제한을 넘을 수 있습니다.
- 지형의 모든 콜라이더는 Ground 레이어(15), Ground 태그, 비트리거, 튀지 않는 바닥 물리 재질로 설정되어 있습니다.
- 배경·장식에는 콜라이더가 없습니다. 앞배경은 화면 가장자리에 배치하는 편이 플레이어를 가리지 않기에 좋습니다.
- 기본 프리팹은 고정 지형입니다. 움직이는 발판이 필요하면 별도의 이동 로직과 Rigidbody2D를 추가해야 합니다.

## 미니맵

Main의 기존 게임 HUD 아래에 MapMinimapHUD가 연결되어 있습니다. 게임 시작 연출 후 HUD의 **미니맵 [M]** 버튼 또는 M 키로 열고, 닫기 버튼·M·ESC로 닫습니다.

- 실제 렌더링되는 지형 이미지와 Background2를 축소해서 보여줍니다. 전체 범위가 들어오도록 자동 맞춤합니다.
- 앞배경(Background1), 먼 배경(Background3), 장식, 플레이어·적 이미지는 범위 계산에서 제외합니다. 플레이어 위치는 청록색 표시로 나타납니다.
- 새로운 프리팹 배치·이동·삭제는 별도 등록 없이 반영됩니다. 지도 표시 중 변경도 0.5초 주기로 확인합니다.
- 기존 맵의 Ground 레이어 / Ground_Grass / BG도 읽습니다. 기존 오브젝트의 이름이나 태그를 덮어쓰지 않습니다.
- 지도에 쓰이는 임시 카메라·복사 렌더러에는 물리나 AI가 없으며, 닫을 때 정리됩니다. 원래 카메라와 지형을 수정하지 않습니다.
- 지도 표시 중 게임 시간은 멈추고 닫으면 이전 배속으로 돌아옵니다. 플레이어 컴포넌트를 꺼 공격을 취소시키지 않습니다.

새 씬에서도 사용하려면 `Resources/Prefabs/UI/MapMinimapHUD.prefab`과 EventSystem을 배치하세요. 전용 RenderTexture는 런타임에 생성됩니다. MinimapPreview 레이어(16)는 지도 표시 전용으로 두세요.

## 원본 리소스

`Resources/Art/Maps`에 원본 사계절 이미지, 메시, 재질, 이미지 생성 프롬프트 `GENERATION.md`가 있습니다. 원본 PNG 픽셀과 투명도는 보존하며, Unity Sprite Rect / Mesh UV로 버전별 영역을 사용합니다.

`Tools > Dotorious > Map Ingredients > Rebuild Prefab Library`는 이 생성 라이브러리와 미니맵 프리팹만 다시 만듭니다. 기존 맵·플레이어·EventSO는 재생성하지 않습니다. 라이브러리 원본을 직접 수정했다면 재생성 전에 백업하세요.
